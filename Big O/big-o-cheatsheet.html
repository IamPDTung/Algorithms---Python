Glossary / Chú thích

Key terms and concepts used throughout this cheat sheet.

Big-O Notation

Asymptotic upper bound

Mathematical notation describing the upper bound of an algorithm's complexity as input size grows to infinity. Used to classify algorithms by their worst-case time or space requirements.

Wikipedia ↗

Time Complexity

Computational time

The amount of time an algorithm needs to complete, expressed as a function of input size (n). Typically measured by counting elementary operations.

Wikipedia ↗

Space Complexity

Memory usage

The amount of extra memory an algorithm uses during execution, excluding the memory occupied by the input data itself.

Wikipedia ↗

Ω(n) — Omega

Best case (lower bound)

Represents the best case scenario — the minimum running time achievable with ideal input.

Wikipedia ↗

Θ(n) — Theta

Average case (tight bound)

Represents the average case — a tight bound both above and below. Reflects typical runtime with random data.

Wikipedia ↗

O(n) — Big-O

Worst case (upper bound)

Represents the worst case — the maximum time an algorithm could take. This is the most common metric for evaluating algorithms.

Wikipedia ↗

log n — Logarithm

Base-2 logarithm

In computer science, log defaults to log₂. O(log n) often appears in divide-and-conquer algorithms (e.g., binary search) where each step halves the problem size.

Wikipedia ↗

n! — Factorial

n factorial

n! = n × (n-1) × ... × 2 × 1. Appears in permutation problems (e.g., brute-force traveling salesman). Grows extremely fast — O(n!) is only feasible for very small n.

Wikipedia ↗

Data Structure

Organization of data

A way of organizing and storing data for efficient access and modification. Each structure has different trade-offs for access, search, insertion, and deletion.

Wikipedia ↗

Sorting Algorithm

Ordering elements

An algorithm that arranges elements in a list in a certain order (ascending, descending). Different algorithms trade off speed, memory usage, and stability.

Wikipedia ↗

Stability

Preserving relative order

A stable sort preserves the relative order of equal elements. Mergesort, Insertion Sort, Bubble Sort are stable; Quicksort, Heapsort, Selection Sort are not.

Wikipedia ↗

In-place Algorithm

Minimal extra memory

An in-place algorithm uses only a small amount of extra memory (O(1) or O(log n)) without duplicating the input. Heapsort and Quicksort are in-place; Mergesort is not.
